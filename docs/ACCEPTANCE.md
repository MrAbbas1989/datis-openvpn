# آزمون پذیرش روی Ubuntu 22.04

این آزمون‌ها روی VPS آزمایشی فاقد مشتری انجام شوند. قبولی تست‌های Python معادل قبولی موارد زیر نیست. نتیجه هر مورد را با تاریخ، نسخه OpenVPN و نام برنامه کلاینت ثبت کنید.

| آزمون | روش | انتظار |
|---|---|---|
| نصب | نصاب را روی Ubuntu 22.04 تازه اجرا کنید | سرویس‌های datis-openvpn/agent/panel فعال؛ Agent در پنل متصل |
| ورود مدیر | رمز غلط، سپس صحیح | رد رمز غلط؛ ورود صحیح؛ خروج نشست را باطل می‌کند |
| اتصال واقعی | کاربر ۵۰GB یک‌روزه بسازید، فایل را در OpenVPN Connect وارد کنید | احراز هویت صحیح؛ IP خروجی متعلق به VPS |
| رمز غلط VPN | اتصال با رمز اشتباه | AUTH_FAILED؛ هیچ ترافیک VPN مجاز نیست |
| محدودیت اتصال | یک حساب با سقف یک اتصال را روی دو دستگاه وصل کنید | دومین اتصال رد شود؛ اولی برقرار بماند |
| حجم | حساب ۰٫۰۱GB بسازید و فایل بیشتر از ۲۰MB دانلود کنید | مصرف افزایش؛ اتصال پس از اتمام سهمیه قطع؛ اتصال مجدد رد |
| زمان | انقضا را دو دقیقه بعد تنظیم و اتصال را باز نگه دارید | با پایان زمان، قطع و عدم امکان اتصال مجدد |
| قطع/غیرفعال | کاربر آنلاین را غیرفعال کنید | اتصال قطع؛ تا فعال‌سازی مجدد ورود رد |
| تمدید | تاریخ و سهمیه را افزایش دهید | مصرف قبلی حفظ؛ اتصال دوباره ممکن |
| صفرکردن مصرف | حین دانلود مصرف را صفر کنید | تنها بایت‌های جدید محاسبه شوند؛ مصرف قدیمی بازنگردد |
| تغییر رمز | رمز یک حساب آنلاین را تغییر دهید | نشست‌های قدیمی قطع؛ رمز قدیمی رد |
| قطع خیلی کوتاه | کمتر از دو ثانیه وصل، انتقال و قطع کنید | شمارنده نهایی نشست ثبت شود |
| بازنشانی Agent | `sudo systemctl restart datis-agent` | نشست‌ها بازنشانی؛ مصرف ثبت‌شده باقی بماند؛ اتصال مجدد مجاز بر اساس سهمیه |
| توقف Agent | `sudo systemctl stop datis-agent` | همه اتصال‌ها قطع/بازنشانی؛ تا شروع مجدد اتصال تأیید نشود |
| راه‌اندازی مجدد سرور | `sudo reboot` | قوانین اختصاصی firewall، وب، OpenVPN و Agent بازگردند؛ مصرف باقی بماند |
| پشتیبان | backup و integrity_check روی کپی | دیتابیس معتبر؛ شمارنده‌ها و حساب‌ها موجود |
| نشت IPv6/DNS | روی Windows، Android و iOS بررسی کنید | IPv6 عمومی مستقیم نشت نکند؛ DNS مورد انتظار |
| TLS وب | تست HTTP/HTTPS و گواهی | HTTP به HTTPS هدایت؛ کوکی Secure؛ ورود کار کند |
| انزوای کاربران | تلاش برای IP خصوصی VPS، metadata و کلاینت دیگر | اتصال مسدود شود |

برای مشاهده وضعیت:

```bash
sudo systemctl is-active datis-openvpn datis-agent datis-panel
sudo journalctl -u datis-agent -u datis-openvpn --since '10 minutes ago'
sudo ss -lntup
```

آزمون قطع Agent را با SSH مستقل انجام دهید تا با قطع VPN، کنترل سرور را از دست ندهید. پس از آزمون توقف:

```bash
sudo systemctl start datis-agent
```

آمار پنل مجموع دو جهت و شمارنده OpenVPN است؛ اختلاف با اندازه فایل به دلیل جهت برگشت و نحوه شمارش طبیعی است. عبور اضافه تا نمونه بعدی ممکن است. اگر سهمیه/انقضا باعث قطع واقعی نشد، این نسخه را برای مشتری فعال نکنید و لاگ بدون رمز/کلید را برای بررسی نگه دارید.
