# Datis OpenVPN Panel

پنل فارسی مدیریت و اکانتینگ OpenVPN برای **Ubuntu 22.04**، با تم بنفش DatisVPN.

**وضعیت انتشار: نسخه آزمایشی 0.1.0.** هر ۳۱ آزمون نرم‌افزاری، از جمله انتقال سوکت، در [GitHub Actions](https://github.com/MrAbbas1989/datis-openvpn/actions/runs/34483605491) روی Ubuntu 22.04 و Python 3.10/3.12 موفق شدند. آزمون‌های خودکار Python و شبیه‌سازی پروتکل مدیریتی وجود دارند؛ نصب کامل روی Ubuntu 22.04 و عبور ترافیک از TUN هنوز در محیط ساخت اجرا نشده‌اند. پیش از انتقال مشتریان، [آزمون پذیرش روی VPS](docs/ACCEPTANCE.md) را انجام دهید. «آماده فروش در مقیاس بالا» یا «ممیزی امنیتی‌شده» ادعا نمی‌شود.

## امکانات

- پنل تحت وب فارسی و واکنش‌گرا؛ ساخت و ویرایش حساب، جست‌وجو و فیلتر وضعیت.
- سهمیه حجمی هر کاربر بر حسب GB، مجموع آپلود + دانلود؛ صفر یعنی نامحدود.
- تاریخ و ساعت انقضا؛ تمدید با تغییر تاریخ، افزایش سهمیه یا صفرکردن مصرف دوره.
- محدودیت اتصال هم‌زمان، شامل اتصال‌های در حال احراز هویت.
- قطع اتصال کاربران غیرفعال، منقضی یا دارای سهمیه تمام‌شده؛ درخواست قطع دستی.
- ثبت مصرف با شمارنده افزایشی، ذخیره در SQLite و ثبت شمارنده نهایی هنگام قطع عادی.
- دانلود پروفایل `.ovpn`، ورود کاربران با نام کاربری و رمز؛ رمز خام ذخیره نمی‌شود.
- نمایش نشست‌های آنلاین، گزارش عملیات مدیر، تغییر رمز مدیر و لغو نشست‌های ورود.
- پشتیبان‌گیری سازگار از دیتابیس در حین اجرا؛ سرویس‌های systemd با کاربر غیر root برای وب و اکانتینگ.

این نسخه **یک سرور** را مدیریت می‌کند. چندنودی، نمایندگی، ربات فروش، درگاه پرداخت، API عمومی، شروع زمان از اولین اتصال، MFA و گزارش مالی پیاده‌سازی نشده‌اند. نام کاربری پس از ساخت ثابت است. حساب‌ها غیرفعال می‌شوند؛ حذف دائمی تاریخچه در رابط وجود ندارد.

## نصب آسان

نیازمندی‌ها: VPS تازه با Ubuntu 22.04، دسترسی root، IPv4 عمومی/دامنه مستقیم، TUN فعال و اینترنت برای دریافت بسته‌ها. پورت VPN و در حالت HTTPS پورت‌های وب باید در فایروال شرکت میزبان باز باشند.

نصاب، OpenVPN را از مخزن رسمی Ubuntu نصب می‌کند؛ وابستگی به اسکریپت angristan ندارد. نصب خودکار روی OpenVPN موجود، UFW فعال یا نصب قبلی/نیمه‌تمام Datis متوقف می‌شود. این محدودیت برای جلوگیری از تداخل سرویس‌هاست؛ نصب دوباره روش به‌روزرسانی نیست.

### ۱. دریافت پروژه

روی سرور Ubuntu 22.04 اجرا کنید:

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/MrAbbas1989/datis-openvpn.git
cd datis-openvpn
```

سپس یکی از روش‌های نصب زیر را انتخاب کنید. دریافت ZIP از GitHub و استخراج کامل پروژه هم ممکن است.

### ۲. نصب بدون نیاز به دامنه (پنل از طریق SSH)

`203.0.113.10` مثال است؛ **IP واقعی سرورتان را جایگزین کنید**:

```bash
sudo bash install.sh --endpoint 203.0.113.10
```

نصاب رمز مدیر `admin` را می‌پرسد؛ رمز حداقل ۱۲ کاراکتر باشد. رمز در خط فرمان یا خروجی نصب چاپ نمی‌شود.

در PowerShell ویندوز یا ترمینال کامپیوتر خودتان اجرا کنید:

```bash
ssh -N -L 8080:127.0.0.1:8080 root@203.0.113.10
```

سپس `http://127.0.0.1:8080` را در مرورگر باز کنید. ترمینال SSH باید باز بماند. در این حالت، پنل روی اینترنت عمومی گوش نمی‌دهد و اتصال مرورگر محلی است؛ مسیر تا سرور با SSH رمز می‌شود.

### ۳. نصب با دامنه و HTTPS

رکورد A دامنه پنل را به IPv4 سرور وصل کنید و پورت‌های TCP 80 و 443 را باز کنید. سپس:

```bash
sudo bash install.sh \
  --endpoint vpn.example.com \
  --domain panel.example.com \
  --email admin@example.com
```

آدرس‌ها را با دامنه‌ها و ایمیل واقعی جایگزین کنید. پنل در `https://panel.example.com` باز می‌شود. نصب خودکار HTTPS برای سرور فاقد تنظیمات قبلی Nginx در نظر گرفته شده است. Nginx و Certbot از بسته‌های Ubuntu نصب می‌شوند؛ تمدید گواهی را با `sudo certbot renew --dry-run` بررسی کنید.

### ۴. انتخاب پورت و پروتکل

```bash
sudo bash install.sh --endpoint 203.0.113.10 --port 1194 --protocol udp
```

یا روی یک نصب تازه:

```bash
sudo bash install.sh --endpoint 203.0.113.10 --port 443 --protocol tcp
```

اگر پنل HTTPS روی همین سرور نصب شود، پورت TCP 443 به وب اختصاص دارد؛ برای VPN پورت دیگری انتخاب کنید. UDP 443 با TCP 443 تداخل پورت ندارد. OpenVPN عادی تضمینی برای عبور از DPI نیست.

## ساخت اولین کاربر

۱. با `admin` وارد شوید و «کاربر جدید» را بزنید.
۲. نام انگلیسی یکتا، رمز حداقل ۱۲ کاراکتری، سهمیه GB، تاریخ UTC و تعداد اتصال را تعیین کنید.
۳. از فهرست کاربران «فایل اتصال» را دانلود کنید.
۴. فایل را در OpenVPN Connect وارد کنید و نام کاربری و رمز همان کاربر را وارد کنید.
۵. برای تست اولیه سهمیه کم مانند `0.01 GB` تنظیم کنید و مراحل پذیرش را اجرا کنید.

پروفایل‌ها تنظیمات مشترک اتصال و کلید `tls-crypt` دارند، اما رمز کاربر داخل فایل نیست. هر کاربر با حساب خودش احراز هویت می‌شود. گواهی سرور با CA و نام `datis-server` بررسی می‌شود؛ گواهی اختصاصی کلاینت صادر نمی‌شود.

**زمان‌ها در این نسخه UTC هستند، نه شمسی یا ساعت محلی ایران.** تاریخ انقضا از زمان تعیین‌شده محاسبه می‌شود؛ از اولین اتصال شروع نمی‌شود. تمدید تاریخ، مصرف را صفر نمی‌کند. برای شروع دوره جدید، سهمیه/تاریخ را اصلاح و در صورت نیاز جداگانه مصرف را صفر کنید.

## دقت و رفتار اکانتینگ

- هر GB برابر **۱٬۰۰۰٬۰۰۰٬۰۰۰ بایت** است.
- شمارنده‌های OpenVPN هر ۲ ثانیه دریافت می‌شوند؛ بررسی انقضا/غیرفعال‌سازی معمولاً هر ۱ ثانیه انجام می‌شود. این اعداد هدف زمانی‌اند و زیر بار تضمین تأخیر سخت ندارند.
- حجم بیش از سهمیه ممکن است تا نمونه بعدی و اجرای قطع، ادامه پیدا کند. مثلاً در مجموع ۱۰۰ مگابیت‌برثانیه، ۲ ثانیه ترافیک حدود ۲۵ مگابایت است؛ تأخیر و صف می‌توانند این مقدار را بیشتر کنند. محدودسازی دقیق در سطح هر بسته پیاده‌سازی نشده است.
- گزارش تکراری دوباره حساب نمی‌شود؛ شمارنده کاهشی مصرف را کم نمی‌کند. صفرکردن مصرف، مبنای شمارنده نشست زنده را تغییر نمی‌دهد.
- قطع عادی، مصرف نهایی را ثبت می‌کند. قطع برق/کرش سخت ممکن است آخرین بایت‌های بعد از نمونه ثبت‌شده را از دست بدهد. این سامانه اکانتینگ تراکنشی بدون هیچ اتلافی نیست.
- قطع رابط مدیریت با `management-signal` باعث بازنشانی اتصال‌های OpenVPN می‌شود؛ اتصال جدید به تأیید Agent نیاز دارد. Watchdog برای توقف Agent هنگ‌کرده تعریف شده است. صحت این رفتار باید روی VPS واقعی آزمون شود.
- اطلاعات مصرف، آمار داخلی OpenVPN است؛ الزاماً معادل صورتحساب ترافیک دیتاسنتر شامل سربار نیست.

## مدیریت سرور

```bash
# وضعیت
sudo systemctl status datis-openvpn datis-agent datis-panel

# لاگ‌ها
sudo journalctl -u datis-agent -u datis-openvpn --since '10 minutes ago'

# تغییر/بازیابی رمز مدیر؛ همه نشست‌های قبلی او باطل می‌شوند
sudo datisvpn admin admin

# پشتیبان سازگار دیتابیس؛ مسیر باید قابل نوشتن برای datisvpn و فایل جدید باشد
sudo datisvpn backup /var/lib/datisvpn/backup-2026-09-10.sqlite
```

تاریخ نام فایل مثال است. پشتیبان دیتابیس به‌تنهایی شامل CA/گواهی‌ها/تنظیمات نیست. راهنمای کامل بازیابی، نگهداری و تمدید گواهی: [OPERATIONS](docs/OPERATIONS.md).

## اجرای توسعه و آزمون

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest -q
```

برای پنل محلی بدون OpenVPN (وضعیت اکانتینگ به‌درستی «قطع» نمایش داده می‌شود):

```bash
export DATIS_DB="$PWD/local.db"
export DATIS_SECRET="$(python -c 'import secrets; print(secrets.token_hex(32))')"
export DATIS_SECURE_COOKIE=0
python -m datis.cli admin admin
python -m flask --app 'datis.web:create_app()' run --host 127.0.0.1 --port 8080
```

سرور توسعه Flask برای نصب عملیاتی نیست؛ نصاب از Gunicorn و systemd استفاده می‌کند. Python 3.10 به بالا هدف است. وابستگی‌های اجرا در `requirements.txt` تثبیت شده‌اند. CI روی Ubuntu 22.04 و Python 3.10/3.12 آزمون‌های نرم‌افزاری را اجرا می‌کند؛ CI اتصال واقعی VPN را تست نمی‌کند.
